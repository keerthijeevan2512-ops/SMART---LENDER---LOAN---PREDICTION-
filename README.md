# 🏦 Smart Lender - Loan Approval Prediction System

## 📌 Project Description
Smart Lender is a Machine Learning based web application that helps banks automate the loan approval process. 
It predicts whether a loan application should be Approved or Rejected based on applicant details like Income, Credit History, etc.
This reduces manual work and reduces NPA for banks.

## 🎯 Problem Statement
Banks receive thousands of loan applications daily. Manual verification is slow and error-prone.
This project uses ML to give instant loan approval predictions with ~82% accuracy.

## 🛠️ Tech Stack
- **Language**: Python 3.9
- **Libraries**: Pandas, Numpy, Scikit-learn, Streamlit
- **Model**: RandomForestClassifier
- **Dataset**: Kaggle Loan Prediction Dataset
- **Deployment**: Streamlit Cloud

## 📊 Features
1. User can enter Applicant Details
2. ML Model predicts Loan Status: Approved / Rejected
3. Shows Model Accuracy on sidebar
4. Handles missing values and data preprocessing

## 📁 Files in this Repo
- `app.py` - Main Streamlit application + ML Model
- `loan_data.csv` - Dataset used for training
- `README.md` - Project documentation
